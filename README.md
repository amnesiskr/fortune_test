# 🔮 오늘의 운세

이름과 생년월일을 입력하면 점성술·사주·팔자 기반의 긍정적인 운세를 보여주는 웹 프로그램입니다.

## 미리보기

> 이름과 생년월일 입력 → 사주 간지, 별자리, 5가지 운세, 행운 아이템 출력

## 기능

- **사주 / 팔자** — 생년을 기준으로 천간·지지·오행·띠 자동 계산
- **별자리 (점성술)** — 생년월일로 12별자리 판별 및 기질 설명
- **5가지 운세** — 총운 · 애정운 · 재물운 · 건강운 · 직업운
- **운세 점수** — 80~100점 범위의 긍정적인 점수 및 그래프 표시
- **행운 아이템** — 행운의 색 · 숫자 · 방향 제공
- **일관성** — 이름 + 생년월일 기반 시드로 동일 입력 시 동일 결과 출력

## 사용 방법

별도 설치 없이 브라우저에서 바로 실행됩니다.

```
fortune.html 파일을 브라우저로 열기
```

1. 이름 입력
2. 생년월일 선택 (년 / 월 / 일)
3. **✨ 운세 보기** 버튼 클릭

## 기술 스택

| 항목 | 내용 |
|------|------|
| 언어 | HTML · CSS · JavaScript (Vanilla) |
| 폰트 | Noto Serif KR (Google Fonts) |
| 외부 의존성 | 없음 (CDN 폰트 제외) |

## 파일 구조

```
mytest/
└── fortune.html   # 단일 파일 (HTML + CSS + JS 통합)
```

## 모바일 지원

- `viewport-fit=cover` + `safe-area-inset` — 노치/홈 바 대응
- `font-size: 16px` 입력 필드 — iOS 자동 확대 방지
- 터치 타겟 최소 54px 확보
- 년/월/일 분리 셀렉트 박스 — 모바일 날짜 입력 최적화
- `100dvh` — 모바일 브라우저 주소창 높이 변화 대응

## 운세 산출 방식

입력값(이름 + 생년월일)을 해시 시드로 변환하여 운세 문구와 점수를 결정합니다.  
점수는 항상 80점(4점) 또는 100점(5점)으로, 좋은 운세만 표시됩니다.
